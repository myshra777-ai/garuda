SUPPORTED (Epistemic State) SUPPORTED
A claim or dependency edge that is deterministically proven by compiler type-checking (GO_TYPES confidence 1.0) and corroborated by runtime telemetry or satisfied ADR rules.
Action: Safe to rely on as ground truth.
UNVERIFIED (Epistemic State) UNVERIFIED
Extracted from static AST analysis or documentation, but not yet observed in runtime execution traces (runtime_observations). Never conflated with a failure.
Action: Run integration tests or runtime trace to promote.
CONTRADICTED (Epistemic State) CONTRADICTED
Code directly violates an ingested ADR constraint (`MUST_NOT`), a declarative YAML boundary rule, or a runtime invariant. Triggers immediate quarantine.
Action: Inspect in Surface 06 Change Review & repair.
ALLOW · WARN · REVIEW · BLOCK FAIL-CLOSED
Policy & Talon gate verdicts. In FAIL-CLOSED mode, any net-new BLOCK violation halts pre-commit hooks and returns deterministic self-repair instructions to the AI agent.
Action: Follow `self_repair_instructions` until ALLOW.

Human-readable blast-radius classification. HIGH/SEVERE surfaces (e.g., Search & Pricing Gate with 142 callers) are frozen against automated agent formula changes.
Action: Requires explicit human CLI co-sign (`GARUDA_MCP_APPROVER`).
